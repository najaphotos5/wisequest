# Changelog

Versions use **vXX.XX.XXX** (major.minor.patch):

- **Patch** (last number, `v01.03.000 → v01.03.001`): small fixes such as text edits, typos, swapping a photo, updating a link or address.
- **Minor** (middle number, `v01.03.001 → v01.04.000`): new pages, sections, features, or noticeable design changes.
- **Major** (first number, `v01.04.000 → v02.00.000`): redesigns, new site structure, or changes that break old links.
